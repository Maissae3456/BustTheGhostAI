# 👻 Bust The Ghost AI Game

Welcome to **Bust The Ghost AI**, a fun and strategic game where you use probability and AI to find a hidden ghost on a grid. This project combines Bayesian inference, interactive design, and creative implementation to build something both educational and enjoyable.

## 🎮 What is this game about?

Imagine an 8x13 grid where a ghost is hiding in one of the cells. Your goal is to:

- Find and bust the ghost with the highest possible score.
- Use hints from two noisy sensors:
  - **Distance sensor:** Tells you how close you are to the ghost using colours (Red = found, Orange = very close, Yellow = near, Green = far).
  - **Direction sensor:** Gives you hints like “North” or “East” to guide your search.


## 💡 Why did I build this?

I created Bust The Ghost AI as part of my AI course project to:

- Practice applying Bayesian inference and probabilistic reasoning in a real application.
- Understand how AI can manage uncertainty and make better decisions.

## 🛠️ Technologies Used

- Python for core logic and a web-based interface.

## ✨ What I learned

Through this project, I learned:
